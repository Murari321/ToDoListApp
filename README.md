# 📝 To-Do List App

A simple command-line To-Do List application built using Python.

## Features

- View all tasks
- Add new tasks
- Edit existing tasks
- Search tasks
- Mark tasks as done
- Remove tasks
- Save tasks in a text file

## Technologies Used

- Python
- File Handling
- Git
- GitHub

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Murari321/ToDoListApp.git
```

2. Open the project folder.

3. Run the program

```bash
python todo_app.py
```
